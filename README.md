. Titanic Survival Prediction

.Project Overview
-This project uses Machine Learning classification algorithms
to predict whether a passenger survived the Titanic disaster.

.Algorithms
-Logistic Regression
-Decision Tree
-Random Forest

.Technologies
-Python
-Pandas
-Scikit-learn

.Project Workflow
1-Load the Titanic dataset.
2-Handle missing values.
3-Encode categorical features.
4-Split data into training and testing sets.
5-Scale features for Logistic Regression.
6-Train three classification models.
7-Evaluate models using Accuracy .
8-Predict survival for a sample passenger.
